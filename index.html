How to Install

Because Google charges $5 to host on the Chrome Web Store, Extensive Z is provided completely free and open-source via GitHub. It takes just 30 seconds to install.

1

Download the Extension

Click the Get Extension or Download ZIP button above to get the latest version of the extension source code.

2

Extract the ZIP

Locate the downloaded file and extract (unzip) it to a folder on your computer (e.g., your Documents or Desktop).

3

Open Chrome Extensions

In Google Chrome, type chrome://extensions/ in your address bar and press Enter.

4

Enable Developer Mode

Turn on the Developer mode toggle switch located in the top-right corner of the Extensions page.

5

Load the Extension

Click the Load unpacked button in the top-left corner. Select the extension folder located inside the folder you extracted in Step 2. That's it! Open a new tab to see your new dashboard.

Master Your Workflow with Split View

No more manually resizing windows. The built-in Split View feature allows you to instantly tile your Chrome windows side-by-side.

  • Access via the "Tools" > "Split" tab in the popup
  • Choose from 50/50, 60/40, or 40/60 horizontal splits

Pomodoro & Focus Mode

Advanced Privacy & Ad Blocking

Extensive Z comes with a powerful network-level ad blocker built using Chrome's modern Manifest V3 declarativeNetRequest API.
