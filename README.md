# Extensive Z — Ultimate Chrome Productivity Dashboard

Extensive Z transforms your Chrome New Tab page into a powerful, glassmorphic productivity workspace. It features built-in ad blocking, focus timers, side-by-side split view multitasking, and highly customizable widgets.

## ✨ Features

- **Glassmorphic Dashboard**: A visually stunning replacement for your new tab page, featuring 8 distinct color themes and 14 premium HD wallpapers.
- **Built-in Ad Blocker**: A modern, Manifest V3 network-level ad blocker that automatically filters out 48+ major ad, tracker, and telemetry domains.
- **Split View Multitasking**: Instantly tile your browser windows side-by-side (50/50, 60/40, top/bottom) directly from the extension popup.
- **Pomodoro & Focus Mode**: Set customizable focus timers that automatically block distracting websites while you are in the zone.
- **Tab Sessions & Clusters**: Save groups of tabs and restore them with a single click. Organize your daily workflow into distinct task clusters.
- **Smart Widgets**: 
  - Live Weather
  - Crypto & Gold Tracker (Live prices)
  - Unit & Currency Converter
  - Notes & To-Do Lists
  - Quick Calculator
  - Internet Speed Test

## 🚀 How to Install

Because Google charges a $5 fee for the Chrome Web Store, Extensive Z is provided completely free and open-source right here on GitHub.

1. **Download the ZIP**: Click the green "Code" button at the top of this repository and select **Download ZIP**.
2. **Extract the ZIP**: Locate the downloaded file and extract (unzip) it to a folder on your computer.
3. **Open Chrome Extensions**: In Google Chrome, type `chrome://extensions/` in your address bar and press Enter.
4. **Enable Developer Mode**: Turn on the **Developer mode** toggle switch located in the top-right corner.
5. **Load the Extension**: Click the **Load unpacked** button in the top-left corner. Select the **`extension`** folder (this folder containing the manifest) from the files you extracted.
6. Open a new tab and enjoy your new dashboard!

## ⚙️ Built With

- **Manifest V3**: The latest standard for Chrome Extensions.
- **Vanilla JS/HTML/CSS**: No heavy frameworks, purely lightweight and lightning fast.
- **declarativeNetRequest API**: For efficient, network-level ad and tracker blocking.
